## ⚠ Non-blocking observations (no safe-fix tier action; scripts below where actionable)

1. **`gh` missing on nexus** — gen_morning logs `gh pr list unavailable ([Errno 2] 'gh') — count-only, empty list`. The morning page still writes (PR count comes from git refs) but the PR _list_ renders empty. Fix is a package install (config-tier, not authorized):

   ```sh
   #!/bin/sh
   # fix-nexus-gh.sh — install GitHub CLI on nexus so gen_morning_page.py can list PRs.
   # Run: bash fix-nexus-gh.sh   (asks before changing anything)
   set -e
   printf 'Install gh on nexus via apt? [y/N] '; read a; [ "$a" = y ] || exit 0
   ssh nexus-ts 'sudo mkdir -p -m 755 /etc/apt/keyrings \
     && curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg >/dev/null \
     && echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list >/dev/null \
     && sudo apt update && sudo apt install -y gh && gh --version'
   echo "[OK] gh installed. gh auth login (or GH_TOKEN in the notifier env) still required for private-repo PR lists."
   # Undo: ssh nexus-ts 'sudo apt remove -y gh && sudo rm /etc/apt/sources.list.d/github-cli.list'
   ```
