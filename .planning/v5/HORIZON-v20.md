# HORIZON — War Room to a hypothetical v20

Written 2026-07-12 (Fable finale session). REVISED after Greg answered the
four shaping questions — the first draft (committed 3b6162b) was the
orchestrator's extrapolation; THIS version is built on Greg's stated wants:

- **End state: BOTH DOORS OPEN.** Personal instrument first; every seam
  (auth, no-hardcodes, tenancy) stays product-ready; the product door
  opens on EVIDENCE (someone else wants it), never on a schedule.
- **Autonomy: BUILD THE LADDER, DON'T PICK A DESTINATION.** Each version
  adds at most one receipts-backed rung; climb exactly as far as recovery
  stays boring. No version is allowed to assume "self-governing" is the
  goal.
- **Economy: FORCE THE CHOICE LATER.** Keep the fork explicit and the
  plumbing neutral; decide when it's imminent, not before.
- **Daily bias (the arc's spine): MEMORY THAT COMPOUNDS + AMBIENT /
  GLANCEABLE.** These two outrank everything else in sequencing. Phone
  steering and world aesthetics still happen — they ride along; they
  don't drive.

This is an EXPLORATORY arc, not a contract: v-numbers are eras. Grounded
in the real trajectory (v0 viewer → v1 game+dispatch → v3 Living Studio →
v4 console → v5 finish/connect draft).

## The one-sentence thesis (revised)

Every version should leave Greg with **more remembered** (the estate
never forgets a decision) and **less asked of him** (the board reaches
him; he doesn't poll it) — with autonomy and product-hood as doors the
evidence may open along the way.

  diversity + asset skill, born-managed wrapper DESIGN, old-face

  did any past decision get RE-derived from scratch this month? (If yes,
  memory rung 1 isn't working.)

## Act II — COMPOUNDING (v8–v11)

_"Memory deepens, ambient widens; the autonomy ladder adds single rungs."_

- **v8 — Memory rung 2:** the knowledge graph becomes the board's
  long-term store — per-project decision ledgers, cross-session identity
  for recurring work, staleness surfaced honestly (◷ on old knowledge).
- **v9 — Ambient rung 2:** the soundscape becomes a learnable grammar
  (eyes-free meaning); wall-display glance mode; SHIFT replay ("what
  happened while I slept") as a timeline over receipts + tails.
- **v10 — Ladder rung (ONE):** per-project policies for boring reversible
  work only (read-lane auto-approval, budget envelopes) — verbatim
  receipts + undo mandatory; self-ops joins here (the estate audits
  itself on schedule and files honest-red crises).
- **v11 — Multi-model as a primitive:** dispatches can CARRY a reviewer;
  judge panels as board verbs; disagreement renders as a crisis with both
  transcripts. (P5/P6 caught 7+ real bugs — this pattern has earned
  first-class status.)
- **Act exit question:** after the first autonomous mistake, was recovery
  boring? Did the graph answer beat re-derivation every time it was
  tried?

## Act III — ANYWHERE (v12–v15)

_"Tbilisi-proof: the spine works from a café in Georgia exactly as from

- **Act exit question:** one week in Tbilisi with zero degradation?
  And: did anyone else ask to run it, unprompted?

## Act IV — OPEN QUESTIONS BECOME CHOICES (v16–v20)

_"The far end is deliberately unfixed — these versions exist to force
honest choices with accumulated evidence, plus the craft that makes the
place worth inhabiting."_

- **v16 — Living identity:** earned visual identity per coworker; office
  architecture accretes from real usage (real-progress, spatialized).
- **v17 — Rehearsal:** dry-run dispatches, incident replay from receipts,
  pre-mortems — futures always labeled ⊘ SIMULATED.
- **v18 — Ladder review:** with 8 versions of receipts, decide how high
  the autonomy ladder should actually go — from evidence of recoveries,
  not from vision. Could conclude "this high and no higher."
- **v19 — The economy fork (kept as drafted, by Greg's choice):** real
  ledger vs forever-game vs real-costs/game-rewards — decided then, with
  the plumbing having stayed neutral.
- **v20 — Whatever the evidence earned:** if the doors opened, this is a
  product with a second operator and a self-planning rhythm under Greg's
  gates. If they didn't, it's the best single-operator console that
  exists, remembering everything and asking almost nothing. BOTH are the
  win condition.

## Invariants (violate any of these and it isn't War Room anymore)

1. **Honest data.** ⊘ NO DATA over pretty lies, at every scale — states,
   knowledge staleness, simulations.
2. **Capability is local.** Wire carries intent; machines/tenants hold
   allowlists. Deny by default, forever.
3. **Colorblind-safe.** Shape + word first; color never load-bearing.
4. **Greg gates the irreversible.** Ladder rungs are per-action-class,
   receipts-backed, and revocable; no rung is ever a prerequisite for
   the next version's features.
5. **Real progress only.** Everything on the board derives from observed
   events; the v19 fork decides money and nothing else.
6. **The vault stays upstream** — read-only until a specific, audited,
   Greg-gated write path exists (the v7 graphify routine writes via the
   ROUTINE plane, which already has one: `_inbox` + PR review).
7. **Spine precedence.** When sequencing fights, memory-compounding and
   ambient-delivery win over steering convenience and world aesthetics.

## Falsifiable bets

- Morning consolidation actually reduces surfaces Greg opens (count them,
  v6 exit).
- The graph beats re-derivation (every "what did we decide" trial, v8+).
- Recovery stays boring as rungs are added (every incident, v10+).
- Someone else wants it (v15 checkpoint — one external weekly operator).
- Hosted offerings stay harvestable, not obsoleting (every act boundary).
