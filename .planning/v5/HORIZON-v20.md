Written 2026-07-12 (Fable finale session). REVISED after Greg answered the
four shaping questions — the first draft (committed 3b6162b) was the
orchestrator's extrapolation; THIS version is built on Greg's stated wants:

  (auth, no-hardcodes, tenancy) stays product-ready; the product door
  opens on EVIDENCE (someone else wants it), never on a schedule.
- **Autonomy: BUILD THE LADDER, DON'T PICK A DESTINATION.** Each version
  adds at most one receipts-backed rung; climb exactly as far as recovery
  stays boring. No version is allowed to assume "self-governing" is the
  goal.

  plumbing neutral; decide when it's imminent, not before.
- **Daily bias (the arc's spine): MEMORY THAT COMPOUNDS + AMBIENT /
  GLANCEABLE.** These two outrank everything else in sequencing. Phone
  steering and world aesthetics still happen — they ride along; they
  don't drive.

This is an EXPLORATORY arc, not a contract: v-numbers are eras. Grounded
in the real trajectory (v0 viewer → v1 game+dispatch → v3 Living Studio →
v4 console → v5 finish/connect draft).

## Invariants (violate any of these and it isn't War Room anymore)

1. **Honest data.** ⊘ NO DATA over pretty lies, at every scale — states,
   knowledge staleness, simulations.
2. **Capability is local.** Wire carries intent; machines/tenants hold
   allowlists. Deny by default, forever.
3. **Colorblind-safe.** Shape + word first; color never load-bearing.
4. **Greg gates the irreversible.** Ladder rungs are per-action-class,
   receipts-backed, and revocable; no rung is ever a prerequisite for
   the next version's features.
5. **Real progress only.** Everything on the board derives from observed
   events; the v19 fork decides money and nothing else.
6. **The vault stays upstream** — read-only until a specific, audited,
   Greg-gated write path exists (the v7 graphify routine writes via the
   ROUTINE plane, which already has one: `_inbox` + PR review).
7. **Spine precedence.** When sequencing fights, memory-compounding and
   ambient-delivery win over steering convenience and world aesthetics.
